# Crypto Whale Radar

Whale Radar — market manipulation detection, Nexus trading terminal (Hyperliquid / grid / arb), AI Council, execution safety gates, and Hyperliquid visual backtest.

## Stack
- React + Vite + TypeScript + Tailwind
- Nexus bot protections, Trading Hub, Orderflow
- Public APIs: RugCheck, Ethplorer, DexScreener

## Quick start
```bash
npm install
npm run dev
```
